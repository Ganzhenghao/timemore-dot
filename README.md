# timemore-dot
泰摩dot电子秤

本项目是基于泰摩开放协议[https://github.com/TIMEMORE-COFFEE/open-scale-protocol]  实现的网页链接电子秤的项目

本项目包含以下功能:
1. 基础称量能力, 计时功能
2. 目前包含两种模式手冲模式,标准模式
3. 标准模式仅包含称重,归零(也就是去皮)能力
4. 手冲模式包含以下能力
> 1. 称重能力,归零能力
> 2. 粉水比功能, 用户可以在任何时候点击设定咖啡粉, 此时将称当前的称重记录为咖啡粉重量, 设定咖啡粉后可以自动计算粉水比
> 3. 计时功能, 用户可以开关自动计时功能, 关闭时仅允许手动点击开始计时或者连续敲击两次空格键开始计时, 开启时进行自动计时点击按钮3秒后,用户开始注水自动开始计时
> 4. 冲煮曲线, 可以实时展示用户的冲煮曲线
> 5. 冲煮计划设定, 用户可以设定自己的冲煮计划, 比如 0-10秒注水至45g 10-30秒闷蒸 30-45秒注水至120g 停顿10秒, 55-1分10秒时注水至240g, 1分45秒-2分10秒结束萃取 用户可以选定计划开始冲煮,屏幕展示当前步骤和下一步, 用户可以制定多个计划, 还需要有实时冲煮曲线和计划冲煮曲线的对比
> 6. 历史冲煮记录, 包含曲线
